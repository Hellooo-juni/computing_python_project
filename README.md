# 4. 🌟핵심 기능 5가지🌟

## 📌핵심 기능 1. 과목 선택하기
### 처음에 과목 목록을 보여주고 사용자가 번호를 입력하면 해당 과목 폴더에서 문제를 랜덤으로 가져올 수 있다!
```python
복습할 과목을 선택하세요.

1. 진동공학
2. 계측공학
3. 수치해석
4. 자연과학 코딩기초
5. 시스템제어
6. 기계요소설계
7. 컴퓨팅사고와 SW코딩
8. 전체 과목 랜덤
```
## 📌핵심 기능 2. 문제 이미지 랜덤으로 띄우기
### 일단 각 과목 폴더 안에 문제 사진을 넣어두어야 한다. 예를 들면 컴퓨터 폴더 구조를 이렇게 만들어둘 수 있다.
```
study_questions/
│
├─ 진동공학/
│   ├─ problems/
│   │   ├─ q001.png
│   │   ├─ q002.png
│   │   └─ q003.png
│   └─ answers/
│       ├─ q001.png
│       ├─ q002.png
│       └─ q003.png
│
├─ 계측공학/
│   ├─ problems/
│   └─ answers/
│
├─ 수치해석/
│   ├─ problems/
│   └─ answers/
```
### 문제 사진과 해설 사진의 파일 이름을 맞춰두면 프로그램이 문제를 랜덤으로 뽑고, “다 풀었다” 버튼을 누르면 '같은 이름'의 해설 사진을 보여줄 수 있다! 문제 사진이 q001.png면, 해설 사진도 q001.png로 저장해두는 식이다! 

## 📌핵심 기능 3. 다 풀었다 버튼을 누르면 정답/해설 보여주기
```
[다 풀었다] 버튼
```
### 이 버튼을 누르면 해설 이미지가 뜨는 구조라서 프로그램이 직접 정답을 판단하지 않아도 되고 사용자가 해설 사진을 보고 스스로 맞았는지 확인하면 된다!
## 📌핵심 기능 4. 맞혔는지 틀렸는지 입력하기
### 해설을 본 뒤에 버튼을 누를 수 있다! 
```[맞혔다] [틀렸다]```
이 버튼 중 하나를 누르면 프로그램이 오늘 기록을 업데이트한다! 
```
오늘 푼 문제: 12개
오늘 맞힌 문제: 8개
오늘 정답률: 66.7%
```
## 📌핵심 기능 5. 하루 단위 기록 리셋
가장 쉬운 방법은 프로그램 안에서 오늘 날짜를 확인해서, 저장된 기록 날짜와 다르면 자동으로 기록을 0으로 초기화하는 것이다!

예를 들어 today_record.json 같은 파일에 이렇게 저장해둘 수 있다!

>```json
>{
>  "date": "2026-05-13",
>  "solved": 12,
>  "correct": 8
>}```

다음 날 프로그램을 실행했을 때 날짜가 바뀌어 있으면:
>```json
>{
>  "date": "2026-05-14",
>  "solved": 0,
>  "correct": 0
>}```
이렇게 리셋하면 된다! 

>핵심기능 요약 설명: 즉, 해당 프로그램은 시험기간에 여러 과목을 균형 있게 복습하기 위한 과목별 랜덤 문제 출제 프로그램=> 사용자는 각 과목 폴더에 연습문제 이미지와 해설 이미지를 미리 저장해두고, 프로그램은 선택한 과목 또는 전체 과목에서 문제를 랜덤으로 불러와 화면에 표시한다.  
사용자가 문제를 푼 뒤 ‘다 풀었다’ 버튼을 누르면 해당 문제의 해설 이미지가 나타나며, 이후 사용자가 맞혔는지 틀렸는지를 입력하면 하루 동안 푼 문제 수와 맞힌 문제 수가 자동으로 기록된다.  이를 통해 사용자는 시험기간 동안 특정 과목에만 치우치지 않고 여러 과목을 반복적으로 복습할 수 있다!

# 5. 👤예상 사용자 (나 자신도 OK)

# 6. 🖊️결과물 형태: CLI/GUI/웹 중 선택
사진을 띄우고 버튼을 눌러야 하니까 GUI 앱이 가장 적합할 것 같습니다. Python에서는 tkinter라는 기본 GUI 라이브러리를 쓸 수 있어서 따로 설치하지 않아도 된다고 하여서 수월하게 할 수 있을? 것 같습니다. 제가 원하는 “문제 사진 보기 → 다 풀었다 버튼 → 해설 사진 보기 → 맞힘/틀림 기록” 형태로 프로그램을 짤 수 있다고 합니다.
